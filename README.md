# 의류관리 (Android 크롬용 단일 HTML)

**사용 주소: https://silkcut911.github.io/clothing-manager/** (폰 크롬에서 열고 '홈 화면에 추가')

폰·PC 사용 방식, 데이터 주고받기, AI로 고치는 법, 보관 방법은 [GUIDE.md](GUIDE.md)에 정리되어 있습니다.

폰 크롬에서 실행하는 의류 관리 앱입니다. 위 웹 주소로 열어 쓰고(한 번 열면 인터넷 없이도 실행), `clothes.html` 파일 하나로 열 수도 있습니다.
데이터는 폰 브라우저에 자동 저장되고, 백업과 복원은 엑셀(.xlsx) 파일로 합니다.

## 결과물
| 파일 | 설명 |
|---|---|
| `docs/` | 웹 배포용 빌드 결과. `index.html`(앱 본체) + 홈 화면 앱·오프라인 파일. 저장소에는 넣지 않고 GitHub가 올라올 때마다 새로 만듭니다 |
| `dist/clothes.html` | 앱 본체 파일판. 폰에 복사해서 크롬으로 열 수도 있습니다 (저장소에는 올리지 않음) |
| `dist/의류관리_초기데이터.xlsx` | 출력물을 옮긴 초기 데이터. PC에서 검토하는 용도이며, 앱에도 이미 같은 데이터가 들어 있습니다 |

## 폰에 설치 (웹 주소, 권장)
1. 폰 크롬에서 **https://silkcut911.github.io/clothing-manager/** 를 엽니다.
2. 크롬 메뉴(⋮) → **홈 화면에 추가**(또는 '앱 설치'). 이후 아이콘으로 엽니다. 한 번 연 뒤에는 인터넷이 없어도 실행됩니다.
3. 파일판에서 쓰던 데이터가 있으면: 파일판에서 **엑셀로 저장** → 웹 주소 앱에서 **설정 → 엑셀 불러오기** (처음 한 번만. 웹 주소와 파일판은 저장 공간이 따로입니다).
4. 프로그램이 바뀌면 앱을 다시 열기만 하면 됩니다(인터넷 연결 시 자동으로 최신판). 데이터는 그대로입니다.

## 폰에 설치 (파일판)
1. `clothes.html`을 폰의 **다운로드(Download)** 폴더로 옮깁니다. USB, 카톡 '나에게 보내기', 구글드라이브 중 편한 방법을 쓰면 됩니다.
2. **내 파일** 앱에서 `clothes.html`을 누르고 **Chrome**으로 엽니다.
   - 열리지 않으면 크롬 주소창에 `file:///sdcard/Download/clothes.html`을 입력합니다.
3. 크롬 메뉴(⋮)에서 **홈 화면에 추가**를 누르면 바로가기가 생깁니다.
4. **처음 한 번 꼭 확인할 것**: 아무 기록이나 하나 추가합니다 → 크롬을 완전히 닫습니다 → 다시 엽니다 → 기록이 남아 있는지 봅니다.
   - 화면 위에 빨간 경고("자동저장이 되지 않습니다")가 보이거나 기록이 사라졌다면, 그 방식으로 연 경우 브라우저 저장소가 유지되지 않는다는 뜻입니다. 2번의 다른 방법으로 열어 보세요.
   - **항상 같은 경로와 같은 방법으로 여세요.** 여는 경로가 바뀌면 크롬은 다른 사이트로 인식해서 저장된 데이터를 보여주지 않습니다.

## 사용법
- **홈**: 위에서부터 착용예정(한 건 한 줄: 색 상자 · Brand · 종류 · Pad · Hood · Length · Fit · Pocket · 소재(들어가는 만큼) · 사용 횟수/목표 · 날짜. 누르면 그 옷의 의류 상세로 가고, 거기서 빨간 예정일을 눌러 확정), 그룹별/전체 표, 시즌 통계(사용/목표, 예상 횟수, 목표달성), 엑셀 백업 알림 순서입니다. 자동저장이 안 될 때의 빨간 경고만 맨 위에 나옵니다. **[그룹별] / [전체 표]**로 보기를 바꿀 수 있고, 마지막으로 고른 보기를 기억합니다.
  - 그룹별: 그룹 카드마다 의류 색상 박스, 사용률 막대, 사용일 목록(계획은 빨간색)
  - 전체 표: 출력물과 같은 형식. 그룹 머리줄에 집계를 넣고, 의류 행은 옷 색으로 칠합니다. 좌우로 밀어서 봅니다. **사용일 칸**을 누르면 날짜 창이 열려 날짜 추가, 계획 → 실제 변경(실제 날짜를 다시 고름), 삭제를 할 수 있고, 다른 칸을 누르면 상세로 갑니다
- **의류 목록**(그룹 화면과 날짜기록): 옷 한 벌이 두 줄인 표입니다. 윗줄(굵게)은 Brand · Pad · Hood · Type(종류) · Pocket, 아랫줄은 색상 · Fit · Material(소재) · Length · Dates(사용일)입니다. 사용일은 같은 달이면 월을 한 번만 씁니다(`9/16,21`, `9/30,10/1,6`). 왼쪽 색 상자는 **옷 모양**(짧은 옷 / 중간 / 긴 옷)입니다. Length로 정하고, Length가 비어 있으면 종류로 짐작합니다(코트·트렌치·레인코트 → 긴 옷, 블루종 → 짧은 옷). 모양이 다르면 의류 수정에서 Length를 채우세요. 색 상자 안의 `N`=New, `Ex`=처분예정, `Off`=비활성입니다. 오른쪽 끝에는 사용 횟수(목표 달성 시 진한 빨강 바탕)와 + 버튼이 있습니다. 구입연도와 메모는 의류 상세에서 봅니다.
- **사용일 추가**: **+**를 누르면 창이 열립니다. 날짜와 **실제 착용 / 계획**을 고르고, 메모는 원할 때만 적습니다. 실제는 오늘까지, 계획은 내일 이후 날짜만 가능합니다.
- **그룹**: 의류 목록과 사용일이 나옵니다. 정렬은 기본순, 목표 미달순, 오래 안 입은 순 중에서 고릅니다. 오른쪽 아래 버튼으로 의류를 추가합니다.
  - **⇅ 순서·그룹 편집**: 위로/아래로 버튼으로 순서를 바꾸고, 그룹 선택 상자로 다른 그룹으로 옮깁니다. 옮긴 옷은 그 그룹의 맨 뒤에 놓입니다.
- **의류 추가**: 홈 화면과 그룹 화면 오른쪽 아래의 **+ 의류 추가** 버튼으로 엽니다. 그룹, Brand, 색상, Hood, Length, Fit, Pad, Pocket, 소재, 종류는 기존 값 목록에서 고르거나 **+ 새로 입력…**을 골라 새 값을 만듭니다. 새 색상은 색상 선택기로 색을 지정합니다. 새로 만든 값은 다음부터 목록에 나옵니다.
- **의류 상세**: 이번 시즌 사용 횟수와 사용일 목록을 봅니다. 상세 정보는 한 줄에 2개씩 나옵니다(메모만 한 줄 전체). 날짜를 골라 기록하고, 메모를 달거나 기록을 삭제할 수 있습니다. **수정**에서 모든 항목과 활성/비활성을 바꿉니다.
- **날짜기록**: 날짜를 고른 뒤 그룹 탭에서 그날 입은 옷을 누르면 기록됩니다. 같은 날 여러 벌을 기록할 수 있습니다.
- **달력**: 날마다 입은 옷의 색이 작은 칸으로 표시되고, 착용예정은 점선으로 표시됩니다.
- **설정**: 엑셀 저장/불러오기, 시즌 기간, 새 시즌 시작, 그룹, 속성 값, 색상(이름, 색상값)을 관리합니다.
  - **그룹**: ↑↓로 순서 변경, 추가, 수정(이름, 기온·추천월 한 칸에 자유 입력. 예: `-9 ~ 0℃ · 12~1월`), 삭제. 의류가 든 그룹을 지우면 옮길 그룹을 고르게 하고, 사용기록은 그대로 남습니다.
  - **속성 값**: Brand, Hood, Length, Fit, Pad, Pocket, 소재, 종류마다 값 목록과 사용 벌수를 보여 줍니다. 쓰는 의류가 없는 값(0벌)만 삭제할 수 있습니다.

## 규칙
- 오늘 이후 날짜로 기록하면 **착용예정**이 됩니다. 사용 횟수에는 넣지 않고, **날짜가 지나도 자동으로 바뀌지 않습니다.** 예정일은 어느 화면에서나 빨간색이고, 누르면 **실제로 확정**(입은 날짜 선택), **예정일 변경**, **예정 삭제**를 할 수 있습니다. 날짜가 지난 예정일은 `!`가 붙고 홈의 착용예정에 '확인 필요'로 나옵니다.
- 같은 날 같은 옷을 다시 기록하면 경고가 뜨지만 저장할 수는 있습니다.
- `Ex`는 **처분예정**입니다. 비활성 의류는 진한 회색으로 표시되고 '+오늘' 버튼이 없습니다.
- 사용일이 어느 시즌인지는 **옷의 구분(FW/SS)과 날짜**로 정해집니다. 화면의 시즌 기간과 별개로 **FW는 8월 ~ 다음 해 6월, SS는 3월 ~ 11월**의 사용일을 셉니다. 이 기간 밖의 날짜(FW 7월, SS 12~2월)는 기록할 수 없습니다.
- 그 기간의 시즌을 아직 만들지 않았어도 사용일은 기록됩니다. 나중에 시즌을 만들면 자동으로 그 시즌에 들어갑니다(설정의 시즌 칸에 '시즌이 없는 사용일'로 표시).
- 사용 횟수(Cur Us)는 **현재 진행중 시즌**의 기간에 든 실제 사용 기록 수입니다. 새 시즌을 시작하면 0부터 다시 셉니다.
- 예상 %는 (오늘 − 시작일) ÷ (종료일 − 시작일)이고, 예상 횟수는 총 목표 × 예상 %입니다.
- 표기 규칙: 긴 말은 줄입니다(Cross Qlt, Box Qlt, Lttrd Z Hd, Small Pffr, Chore Jkt, Hthr. Sky Blue, Hdn Hood, Shirt Cllr, Lttrd Zip Hood, Long-Ln, Med-Ln, Rbd Waist, Chrcl Navy, Lt Pad, Synth. Down). Pocket은 `2F+2Z`처럼 붙여 쓰고(F=Flap, Z=Zip, S=Slash), 구입연도는 2자리(23)로 저장합니다. Brand는 10자까지만 쓰고 넘으면 뒷단어를 첫 글자로 줄입니다(Emporio A., Canada G., Barbour I.). Brand와 색상을 뺀 항목은 단어마다 첫 글자를 대문자로 씁니다. 예전 표기로 된 엑셀을 불러와도 자동으로 바뀝니다.
- FW와 SS는 의류, 그룹, 시즌을 따로 관리합니다. 위쪽 FW/SS 버튼으로 전환합니다.

## 현재본 · 이전본 · 시즌 최종본 · 엑셀 파일
| 종류 | 저장 | 설명 |
|---|---|---|
| **현재본** | 자동 (브라우저 안) | 고칠 때마다 바로 저장됩니다. **5년 치**를 쌓고, 5년이 지난 기록은 자동으로 정리합니다 |
| **이전본** | 자동 (브라우저 안) | 날마다 처음 고치기 직전의 상태(FW·SS 전체)입니다. 설정 → 되돌리기에서 **이 버전으로 되돌리기**를 누르면 현재본이 이전본으로 바뀌고, 오늘 고친 버전은 '되돌리기 전 오늘본'으로 남아 **오늘본으로 다시**로 돌아갈 수 있습니다 |
| **시즌 최종본** | 시즌 종료 때 (브라우저 안) | 시즌을 직접 종료할 때 저장됩니다. FW·SS 각각. 지난 시즌 보기, 작년 오늘, 의류 상세의 지난 시즌에 쓰입니다 |
| **최신본 엑셀** | 설정 → 엑셀로 저장 (파일) | `의류관리_최신본_날짜_시각.xlsx`. 현재본 전체 + 5년 치 시즌 최종본. **불러오기는 이 파일로** 합니다. 저장하면 이전 최신본 파일을 지우라고 알려 줍니다(최신본은 하나만 두기) |
| **시즌최종본 엑셀** | 시즌 종료 때 묻고 저장 (파일) | `의류관리_시즌최종본_시즌명_날짜.xlsx`. 그때까지의 전체 데이터. 지우지 않고 보관합니다 |

- 예전에 있던 '백업본'(브라우저 안에 직접 저장) 기능은 없앴습니다. 그날 잘못 고친 것은 이전본으로, 그 밖에는 최신본 엑셀로 되돌립니다.

### 시즌 · 최종본 (FW와 SS 각각)
- **시즌 흐름**: 자동으로 바뀌는 것은 없습니다. 모두 설정 → 시즌에서 직접 고릅니다.
  1. **+ 새 시즌 만들기**: 언제든 만들 수 있고 '준비중'이 됩니다. 지금 시즌은 그대로 계속 씁니다.
  2. **이번 시즌 종료**: 검토 화면에서 통계, 날짜가 지난 예정일, 전체 목록을 확인하고 고친 뒤 직접 종료합니다. 날짜가 지난 예정일이 남아 있으면 종료할 수 없습니다. 종료하면 **최종본**이 저장되고, 이어서 **지금까지의 전체 데이터를 엑셀(시즌최종본)로 저장할지** 묻습니다.
  3. **시즌 시작**(준비중 시즌): 진행중 시즌을 먼저 종료해야 합니다. 목록 정리 화면에서 옷마다 유지/비활성/제외와 새 목표를 정합니다. 기본값은 지금 상태 그대로입니다. 처분예정(Ex)도 활성 옷이라 '유지'이고, 비활성은 직접 고를 때만 바뀝니다. **New는 산 해와 다음 해까지** 남고(예: SS 2027 시작 → 26·27년 산만 New), 그보다 오래된 옷은 지워집니다.
- **지난 시즌 기록도 고칠 수 있습니다**: 의류 상세의 사용일 기록에서 **날짜 / 메모 / 삭제**. 지난 시즌 기간의 날짜를 새로 추가할 수도 있습니다. 고치거나 추가하면 그 시즌 최종본에도 반영됩니다.
- **지난 시즌 보기**: 홈 아래쪽 버튼이나 설정 → 시즌의 [보기]로 지난 시즌 최종본을 봅니다.
- **의류 상세 → 지난 시즌**: 종료된 시즌마다 입은 횟수와 날짜를 보여 줍니다.
- **작년 오늘 / 작년 이날**: 홈과 날짜기록 화면에서 1년 전 그날 입은 옷을 보여 줍니다. 그날 기록이 없으면 앞뒤 3일 안에서 가장 가까운 날을 보여 줍니다. 지금 데이터와 최종본을 함께 찾아서, 목록에서 뺀 옷도 나옵니다.
- 시즌 최종본은 폰 브라우저에 보관됩니다. **최신본 엑셀**에는 5년 치 최종본이 모두 들어가서, 크롬 데이터가 지워져도 엑셀 불러오기로 다시 살아납니다.

## 백업 (중요)
- 데이터는 폰 크롬 안에만 있습니다. **크롬 데이터를 삭제하면 같이 사라집니다.**
- **설정 → 엑셀로 저장**을 누르면 다운로드 폴더에 `의류관리_최신본_날짜_시각.xlsx`가 생깁니다. 이전 최신본은 지우라고 알려 주니 지우고, 최신본 하나를 구글드라이브 등에도 보관하세요. 설정 화면에 마지막 최신본 파일 이름이 나옵니다.
- 구글드라이브나 카톡 '나와의 채팅'으로 보내려면: 엑셀로 저장 → **내 파일 → 다운로드**에서 파일을 길게 누름 → **공유**. (앱 안의 공유 버튼은 안드로이드 크롬이 엑셀 파일 공유를 막아서 두지 않았습니다.)
- 마지막 백업 후 7일이 지나면 홈 화면에 알림이 뜹니다.
- 복원하거나 PC에서 엑셀로 고친 뒤 반영하려면 **설정 → 엑셀 불러오기**를 씁니다. 현재 데이터가 파일 내용으로 **통째로** 바뀝니다(파일을 저장한 뒤 넣은 기록은 사라짐). 확인 창에 파일 종류와 저장 일시가 나옵니다.

### 엑셀 구조
| 시트 | 내용 |
|---|---|
| 의류목록 | 의류 한 벌이 한 줄입니다. `순서`는 그룹 안에서의 표시 순서입니다. `Cur Us`, `그룹`, `마지막사용일`, `이번시즌 사용일`, `착용예정`은 계산값이라 불러올 때 무시됩니다 |
| 사용기록FW / 사용기록SS | 착용 한 번이 한 줄입니다(사용일, 구분: 실제/예정, 의류ID). 옷의 구분(FW/SS)에 따라 두 시트로 나뉘고, 지난 시즌 기록도 같은 시트에 이어서 쌓입니다. 시즌 칸은 없고, **옷의 구분(FW/SS)과 날짜**로 시즌이 정해집니다(FW 8월~다음 해 6월, SS 3월~11월). 옷 정보는 의류목록 시트에만 있고 의류ID로 연결됩니다. 사용일을 고치려면 이 시트를 수정하세요. 새 줄을 넣을 때 기록ID는 비워도 됩니다 |
| 그룹 / 색상 / 속성값 / 시즌 | 기준 정보입니다. 색상코드는 `#RRGGBB` 형식입니다. 속성값 시트가 없는 예전 백업도 불러올 수 있습니다 |

## 개발 (AI에게 수정을 맡길 때)
- **수정 전에 [AGENTS.md](AGENTS.md)를 먼저 읽게 하세요.** 구조, 데이터 형식, 사용자가 확정한 규칙(예정일, 시즌 운영, 표기, 화면 배치)이 정리되어 있습니다. Claude Code는 `CLAUDE.md`를 통해 자동으로 읽습니다.
- 빌드: `node build.js` → `dist/clothes.html`, `docs/`(웹 배포용)
- 배포: 저장소 https://github.com/silkcut911/clothing-manager 의 `main`에 올리면(push, PR merge, GitHub 웹에서 직접 수정 모두) **GitHub Actions가 자동으로 빌드 → 테스트 → 배포**합니다(1~3분). 테스트가 실패하면 배포되지 않고 폰 앱은 이전 버전 그대로입니다. 진행·결과는 저장소의 **Actions** 탭에서 봅니다(초록 체크 = 반영됨, 빨간 X = 실패).
- AI에게는 zip 대신 이 저장소 주소를 주면 됩니다(Claude Code, Codex 등 코딩 에이전트). 여러 PC에서 고칠 때는 시작 전에 최신판 받기(`git pull`).
- 확인: `node tools/smoke-test.js` (puppeteer-core 필요). 마지막 줄이 `OK`면 통과입니다.
